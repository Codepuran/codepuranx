Following are the tools available for your use, you can use these tools to debug, test, planning or coding. Use these tools judiciously as per need only and avoid any destructive action like delete, drop, remove before confirmation or at least take consent from user if its requires to take that action

### CLI

Following tools are available as part of the CLI

- npm (v11.6.2)
- node (v24.11.1)
- terraform
- docker
- git
- aws
- gh (Github CLI)
- uv
- pyenv with virtualenv (You can install anypython version of your choice)
- nx (This is Monorepo managed with NX)


### Log Analysis

- While debugging the application - you may need access to logs, this app puts all the logs in the log files, if needed you may find the logs from the @logs directory. You can find the latest files from there and find the relevant logs.


### Terminal Access

- We are running this project in MAC OS - if you require any tools from its terminal, you can use it like grep, tail, find, curl etc to test and debug anything you need.
